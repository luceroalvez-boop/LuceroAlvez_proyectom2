# Proyecto M2 - Integración de Retos en Python
## Descripción del Proyecto
Este script unifica los retos anteriores utilizando un menú interactivo, bloques 'try-except' para el manejo de excepciones y validaciones con estructuras de control.
## Reflexión sobre la lógica de Programación 
El uso de estructuras de control (como condicionales y bucles 'While') combinado con el manejo de excepciones mejoro significativamente mi lógica de programación. Me permitió estructurar programas más robustos que no se detienen abruptamente ante un error del usuario, facilitando un flujo de datos controlado, seguro y una mejor experiencia de uso.
